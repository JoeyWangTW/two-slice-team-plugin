## Codebase Patterns
- Plugin source lives in `plugin/` dir in repo root, symlinked to `~/.claude/plugins/two-slice-team/`
- Empty directories need `.gitkeep` files to be tracked by git
- plugin.json follows Claude Code plugin spec with name, description, and skills array
- Each skill has name, description, and path to SKILL.md
- Templates use `{{PLACEHOLDER}}` syntax (PROJECT_NAME, VISION, DATE, CONVENTIONS, ALLOWED_COMMANDS)
